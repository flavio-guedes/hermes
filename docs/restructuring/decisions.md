# Decisões · Hermes

## Estrutura

Cada decisão deve registrar:

- data;
- contexto;
- problema;
- evidência;
- decisão;
- impacto;
- responsável;
- resultado;
- status.

## Decisão 001 · Base da reestruturação

**Status:** Definida

**Decisão:** O Hermes deve evoluir para uma arquitetura orientada a dados, contexto, execução, evidência e histórico.

**Motivo:** Reduzir duplicação, melhorar observabilidade, facilitar retomada e tornar a operação escalável.

**Impacto:** Dashboard, fila, agentes, bots, Radares e Command Bar devem consumir uma mesma base operacional.
