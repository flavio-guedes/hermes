# Bot Mode · Hermes

## Princípio

```text
Agente = capacidade
Bot = instância operacional contextual
```

Exemplos:

```text
Mercúrio → EPQ → Bot Follow-up PMERJ
Mercúrio → Flávio → Bot CRM
```

## Bot Builder

Nome, agente base, projeto, contexto, função, canais, capacidades, autonomia, regras e limites.

## Estados

Disponível · Raciocinando · Executando · Aguardando · Delegando · Em comunicação · Bloqueado · Erro · Pausado

## Grupos

Objetivo, contexto, membros, supervisor, ordem e regras.

## Orquestração

Interpretar objetivo → selecionar capacidades → delegar → acompanhar → validar → registrar resultado → escalar bloqueios.
